# DhikzxCloud - Profil

Web profil statis (HTML + CSS + JS), tanpa build step. Deploy ke GitHub Pages / Netlify / Vercel.

File yang perlu kamu taruh sendiri:
- `payment/payment.jpg` (gambar QR All Payment)

Edit cepat:
- Warna: variabel di atas `styles.css` (`--blue` = satu-satunya warna terang)
- Nomor WhatsApp kontak: `WA_CONTACT` di `main.js`

- Thumbnail link WhatsApp: ganti semua `https://DOMAIN-KAMU` di `index.html` dan `payment/index.html` dengan domain deploy-mu (harus https dan URL lengkap). Kalau thumbnail belum berubah, WhatsApp menyimpan cache lama: coba tempel link dengan tambahan `?v=2`.
